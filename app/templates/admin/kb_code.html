✏️ Correction code

Fix a wrong answer from inside the chat, the moment you spot it. No forms, no hunting through the answer book.

How to use it

When the assistant gives a bad answer, type this into the same chat box:

YOURCODE cafeteria :: Our cafeteria serves hot meals all day. Ask at reception and they will point you to it.

That corrects the answer for this hospital only — the safe default. To change it for every hospital using the suite, add the word global:

YOURCODE global cafeteria :: Our cafeteria serves hot meals all day.

The name in the middle (cafeteria) is the answer's short name — you can see them all in the Answer book. The :: separates the name from the new wording.

⚠️ Two locks, not one — and why

You asked for a secret code. I built that, but I also added a second lock, and I want you to know why.

The chat box is open to the whole internet. Anyone can send messages to it without signing in — that is what makes it useful to patients. If the code were the only lock, then anyone who guessed it could rewrite what your hospital tells sick people about medicines, fees and emergencies. A word can be guessed, read over your shoulder, or left behind on a shared computer.

So a correction needs both:

  • you are signed in as the Super Administrator in that browser, and
  • you type the code.

The code still does the job you wanted: an ordinary sentence is never mistaken for an edit, and a colleague borrowing your signed-in tablet cannot change an answer by accident. But a stranger who guesses the code gets nothing, because they are not signed in. Every correction is recorded with your name and the previous wording is kept.
