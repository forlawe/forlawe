How to fix — step by step (Render)

For Twilio SMS (real SMS to patients)

  1. Go to twilio.com/console → copy Account SID (starts AC) and Auth Token
  2. Buy a phone number in Twilio console → Phone Numbers → Buy → choose US number (SMS works to Nigeria, but needs verification if trial)
  3. In Render Dashboard → hospital-suite → Environment → Add:
    SMS_MODE=twilio
    TWILIO_ACCOUNT_SID=AC...
    TWILIO_AUTH_TOKEN=...
    TWILIO_FROM=+1415... (your Twilio number)
  4. Save → wait 2-3 min
  5. Test below with your own number +2348012345678 — must be verified in Twilio if trial account (Console → Verified Caller IDs)

For Twilio WhatsApp (real WhatsApp)

  1. In Twilio console → Messaging → Try it out → WhatsApp sandbox → you see whatsapp:+14155238886 and a code like join bright-hour
  2. On your phone, open WhatsApp, send message join bright-hour to +14155238886 — you must do this, otherwise sandbox blocks you
  3. In Render add:
    WHATSAPP_MODE=twilio
    TWILIO_WHATSAPP_FROM=whatsapp:+14155238886 (sandbox) — for production, use your approved WhatsApp sender
    Keep SID, Token, FROM from above
  4. Save → wait 2-3 min → test below
  5. For production WhatsApp (not sandbox), you need to request WhatsApp sender approval in Twilio — takes 1-2 days

Common mistakes in Nigeria

  • 080... instead of +234... — always use +2348012345678, not 08012345678, not +234080...
  • Trial account — Twilio trial can only send to verified numbers. Add your number in Console → Phone Numbers → Verified Caller IDs → Add
  • WhatsApp sandbox not joined — you MUST send "join <code>" to Twilio WhatsApp number first, otherwise every message fails with "not in sandbox"
  • FROM format wrong — SMS FROM is +1415... , WhatsApp FROM is whatsapp:+1415... — don't mix
  • SMS_MODE still sandbox — if you set SID but leave SMS_MODE=sandbox, no real SMS sent — set to twilio
  • Sender ID not approved — for Nigeria, alphanumeric sender ID needs approval. Use Twilio number (+...) for testing, not HOSPITAL text

Need cheaper Nigeria SMS? Use Termii (recommended)

Twilio SMS to Nigeria is expensive and sometimes blocked by DND. Termii is Nigerian, cheaper, delivers to MTN/Glo/Airtel/9mobile. Setup: accounts.termii.com → get API key + sender ID (e.g. HOSPITAL) → in Render set SMS_MODE=termii, TERMII_API_KEY=..., TERMII_SENDER_ID=HOSPITAL. Twilio remains fallback if Termii key missing.
