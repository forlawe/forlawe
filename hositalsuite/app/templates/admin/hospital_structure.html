🏥 Hospital Structure — One Page, Everything

Founder asked: "Merge Department vs Clinic admin — I don't get you". This page merges them visually, but keeps data separate behind. Department = who you work for (HR/roster). Clinic = where patient meets doctor today (queue/TV). No data loss.

How to read this page:
  • Departments = Surgery, Family Medicine, Nursing — has HOD name/phone, roster mode (two 12h vs 24h), staff per shift
  • Clinics = DENTAL, OPD, ANC, O&G, Eye — where triage puts patient. Code is what system stores.
  • Rooms = Room 1 … Room 8 — which clinic this room belongs to (optional)
  • Destinations = LAB, PHARMACY, BILLING, LAHSMA, Theater, Wards — where doctor sends patient next. Voice says Place field.
  • TV Screens = MAIN, DENTAL, OPD, PHARMACY — /tv/CODE boards, volume per TV, voice 2M2F daily EN+YO
