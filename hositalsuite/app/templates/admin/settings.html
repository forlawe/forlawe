🔔 Push Notifications — Per-Hospital VAPID (Multi-Hospital, Works Closed Like Alarm)

Each hospital can have own VAPID keys so push shows hospital name/logo on phone home screen when app closed like alarm. If empty, global env VAPID_PUBLIC_KEY/PRIVATE/SUBJECT used. Generate via: python -m py_vapid --gen or npx web-push generate-vapid-keys. Cost saver: push is FREE vs SMS ₦3-4 each, 80-90% saving. Works on Chrome, Firefox, Edge, Samsung, Opera, Safari 16.4+ (PWA installed). Loading time: push payload <1KB, slow internet optimized. Manifest uses /branding/logo/192,512,maskable,apple — per-tenant logo shows on phone home screen.

Test push at /alert-settings → Enable push → Test alarm. Icon is /branding/logo (hospital logo). Works closed like alarm, no SMS inside except emergency/complaint.
