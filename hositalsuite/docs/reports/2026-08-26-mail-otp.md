# Why the 6-digit code never arrived — and how to turn the mail van on

**Version 1.7.10.** Code is local until you paste a new GitHub token.

## What was wrong (honest)

The app **created** the 6-digit code. It **did not send** it.

| What we thought | What was actually happening |
|---|---|
| “Email the code” | The only van was **SMTP** (old office mail, port 587) |
| Render would send it | Render **blocks** that port. And `SMTP_HOST` was empty |
| The person would get a letter | They got a screen that **lied**: “We sent a code” |
| SMS would save them | Sign up has **no phone**, so SMS never ran |

So the code sat in the database. Nobody’s Gmail ever saw it.

## What we changed

| Change | Why |
|---|---|
| New mail van uses the **web** (Resend, or Brevo, or SendGrid) | Those use HTTPS. Render does not block them |
| Old SMTP still works if you really have a mail server | Spare, not the first try |
| The activate screen now **tells the truth** | “The code did not leave” + what to do |
| System Health has **Send a test letter to my email** | You can see it work before a nurse signs up |
| Codes are **not** printed on the public page in live mode | That was a hole |

Until you add a free key (below), the System Admin can still tap **Confirm email** on Users so a person is not stuck.

## What YOU must do (5 minutes, free)

The code cannot invent a mailbox. You must give it a van.

### Easiest: Resend (100 letters a day free)

1. Open [resend.com](https://resend.com) and create an account.
2. Add and verify **your domain** (or, for a first test only, they give you `beth.t@example.com` which can only write to **your** own inbox).
3. Copy the API key (starts with `re_`).
4. On **Render** → your service → Environment:
   - `RESEND_API_KEY` = the key
   - `MAIL_FROM` = `Hospital Suite <leo.a@example.org>`  
     (must be an address Resend has verified)
5. Save. Wait for the restart.
6. Sign in as System Admin → **System Health** → **Send a test letter to my email**.
7. Open that inbox (and Spam). If the test letter is there, Sign up codes will arrive too.

### Spare vans

Same idea: `BREVO_API_KEY` + `MAIL_FROM`, or `SENDGRID_API_KEY` + `MAIL_FROM`.

## How we checked

| Check | Result |
|---|---|
| No key → mail is “off”, send returns a plain reason | Yes |
| Fake Resend key + mock web call → letter is posted to Resend with the 6 digits | Yes |
| Sign up with no key → screen says the code did **not** leave | Yes |
| Account is still saved so Admin can Confirm email | Yes |
| Health JSON shows `"mail": "off"` until a key is set | Yes |
