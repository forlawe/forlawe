# Gate 2 — Queue / My Visit Journey

Date: 15 September 2026

## Scope

This is the first Gate 2 page pass. It stays on the patient queue entry and
its private journey wording; booking, emergency, complaint, feedback, and
status pages are deliberately untouched.

The acceptance bar for this pass was: thumb-first order, clear feedback,
forgiving form fields, calm honest copy, and no regression of the shared Gate
1 design system or Fast Track consent rules.

## What changed

### Queue entry (`/queue/join`)

- Added a clear three-step form structure with fieldsets and legends:
  choose a service, identify the person waiting, then optionally choose Fast
  Track.
- Added real labels, `for`/`id` links, `autocomplete` hints, an optional phone
  explanation, and a single primary submit button.
- Added an `aria-live` feedback region. Validation flashes now use `role=alert`
  for errors and `role=status` for other messages.
- Fast Track is no longer presented as a large always-on block. It starts as a
  clearly optional action and opens only when the patient asks for it or picks
  the Fast Track service. Its consent remains optional in the initial HTML and
  becomes required only when the premium service is active; the server still
  enforces it independently.
- Preserved the owner's pinned routing copy and the one shared Fast Track
  consent sentence.
- Kept the three-service dropdown and emergency separation unchanged.

### Private tracker (`/queue/ticket`)

Changed the instruction from promising that the patient would hear their name
to telling them to go to the desk when their number appears. This matches the
page's existing privacy promise that the public display shows the number, not
the patient's name.
