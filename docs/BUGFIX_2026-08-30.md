### 3) Voice recording not saving/playing (08:03 screenshot)
- **Screenshot**: Voice Studio Record 00:10 waveform + Save Recording to Bank circled failing, audio player 0:00/0:00
- **Root cause**: Frontend MediaRecorder on Android Chrome produces `audio/webm;codecs=opus` blob, filename `queue_waiting_en_123.webm`, but backend `app/native_voice.py` only allowed mp3/wav/ogg/m4a/mp4 — rejected webm. Also JS did fetch POST expecting redirect, but checked resp.ok incorrectly.
- **Fix**:
  - `app/native_voice.py`: allow webm, opus, detect mimetype, default to webm, check size <100 bytes error, content-type audio/webm
  - `app/views/native_voice.py`: upload_voice_sample and upload_phrase allow webm/opus, detect mimetype, return JSON when X-Requested-With XMLHttpRequest or Accept application/json (for fetch), size check <100
  - `app/templates/admin/native_voice.html`: completely rewritten — detects supported mimeType, shows status, disables button while saving, handles JSON response, shows troubleshooting tips, responsive grid, table-wrap.
  - Tested: bulk-upload also allows webm.
